# v0.7.1

## Highlights
- Node pods view: each node now exposes a `/pods` child folder that lists pods scheduled on the node, backed by selector-scoped caches so the view streams updates without starting cluster-wide pod watches.
- Kubectl-style intents handle cluster resources again; commands like `kc get nodes` resolve cluster-scoped resources and navigate to them correctly.
- Resource counts stay accurate under bursty informer updates by replaying events that arrive while a recount is already in flight.

## Documentation
- Added the node pods folder design doc outlining the selector-scoped cluster approach and navigation flow.
- README now calls out child object hierarchies and clarifies quit shortcuts (F10/Esc+0/Ctrl+Q).
