# v0.8.0

## Highlights
- Commands: run custom shell commands in a panel, either interactive (attach to the TUI) or non-interactive with watch/refresh intervals; Enter focuses interactive commands, Esc Esc drops back to navigation.
- Terminal fixes: Ctrl+C / Ctrl+Z handling in the integrated terminal and command widgets behaves correctly again.
- Function key bar is mode-aware: describe/manifest/command modes hide resource actions and reflect command focus state.

## Bug fixes / small improvements
- Masked function-key actions in read-only modes so view/edit/delete/copy/create are not offered when they can’t run.
- Added unit tests to cover function bar mode behavior and capability masking.
