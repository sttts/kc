# v0.7.4

## Highlights
- Added kubectl-style impersonation flags (`--as`, `--as-group`, `--as-uid`) and thread the identity through cluster pools, terminal overlays, and cache keys so sessions respect the chosen user.
- Forbidden peeks are treated as empty results and blocked counts now return zero, keeping the UI usable for RBAC-limited roles instead of erroring.
- Automatically register table cache types and pass impersonation into kubeconfig copies; YAML artifacts are ignored by default for cleaner worktrees.

## Testing
- Envtests now cover limited-access browsing and forbidden resource group peeks to guard RBAC behavior.
