# v0.7.2

## Highlights
- Added `kc version` command that prints kc build metadata, client-go version from go.mod, and the server version with discovery logging.
- Controller-runtime and klog verbosity now stay aligned so `-v` consistently controls zap logs and `~/.kc/debug.log` output.
- RBAC denials while peeking folders are handled gracefully: forbidden resources render as empty instead of breaking navigation for limited users.
- Split the UI core into focused view/update/input files to make future fixes less error-prone.

## Testing
- New unit tests cover the version command, logging alignment, and resource-group peek handling to keep RBAC and verbosity behaviors locked down.
